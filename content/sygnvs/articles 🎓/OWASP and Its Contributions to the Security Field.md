Security professionals across the world are constantly at war over what we consider to be the most important policies, practices, or implementations to keep our clients safe when conducting business online. Should we choose EDR or XDR, Windows or Linux, in-house or cloud-based? Should we rely on single-sign-on or enforce individual workers using a password manager to organize their credentials?

However, the one area of consensus that seems to be a constant throughout the cybersecurity industry is that OWASP has contributed more to the field than any other foundation. 
## Where did OWASP come from?

![[Gemini_Generated_Image_kyoazskyoazskyoa.png]]

OWASP was founded in 2001 as a grassroots effort to improve software security - for those of us who remember the dawn of personal computing, we remember how omniscient the cyber threat was. Websites could be easily loaded with malware, a single update could brick a PC in minutes, and almost any developer at the time could attest to the general ignorance running rampant within the upper echelons of the space with regards to general security posture. 

OWASP started as a simple awareness campaign, founded by Mark Curphey - driven by the vision of "trustworthy computing," Curphey aimed to illustrate the idealistic path for developers towards more secure software packages (Kahn, *Medium*). By creating an expansive emailing list, top executives, project managers, and lead developers were suddenly privy to the looming threat of cyber attackers looking to profit off of their ignorance.

![[0_y_zV26kf2U5cHNwX.webp]]

Today, OWASP stands for the *Open Worldwide Application Security Project,* a testament to the scope of this organization's influence. Of course, like all of our favorite tools, OWASP is an open-source project - this means that the many offerings of the foundation are completely free for organizations to leverage, modify, or distribute (*Linux Foundation*). 

## So, what is OWASP Offering for Us to Use?

![[Gemini_Generated_Image_hkpqovhkpqovhkpq.png]]

Perhaps the most famous offering that millions of cybersecurity professionals are using every single day is the [Top 10 Global Cyberthreat List](https://owasp.org/www-project-top-ten/). While this resource has certainly attracted a well-deserved reputation amongst industry leaders, it does detract from the many other offerings of the organization: the educational resources, cybersecurity news, tools, documentation, web application standards, guides, and forums offered provide the most comprehensive security training platform on the internet (Loshin). 

The true depth of the projects being hosted is brought to the forefront with a simple headcount of current, active tasks: more than 250 assignments are open and being contributed to on any given day. Of those 250, there are 18 which are considered flagship projects - among those 18, the OWASP Top 10 is considered the most important.

## The Many Flagship Projects of OWASP

 - ### **Amass** 
- A tool for in-depth [domain name system](https://www.techtarget.com/searchnetworking/definition/domain-name-system) enumeration, attack surface analysis and external asset discovery.

 - ### **Application Security Verification Standard** 
- A framework for testing web application security controls and a set of secure development requirements.

- ### **Cheat Sheet Series** A
- set of guides for good security practices for application development.

- ### **CSRFGuard** 
- A library that implements patterns that can minimize the risk of cross-site request forgery, also known as CSRF, attacks.

- ### **CycloneDX** 
- A standard for [bill of materials](https://www.techtarget.com/searcherp/definition/bill-of-materials-BoM) security and supply chain component analysis.

- ### **Defectdojo** 
- A vulnerability management tool for the security testing

- ### **Dependency-Check** 
- Does dependency checking for vulnerabilities as part of software composition analysis.

- ### **Dependency-Track** 
- A component analysis platform that identifies risks in the software supply chain.

- ### **Juice Shop** 
- An example web application designed to incorporate all of the underlying vulnerabilities listed in the OWASP Top 10 list. It's written entirely in JavaScript and provides a hacking target for [penetration testers](https://www.techtarget.com/searchsoftwarequality/tip/Everything-you-need-to-know-about-software-penetration-testing) and other security professionals.

- ### **Mobile Security Testing Guide** 
- A set of standards for mobile application security testing, security requirements and verification.

- ### **ModSecurity Core Rule Set** 
- A set of attack detection rules used in web application firewalls.

- ### **Offensive Web Testing Framework** 
- A framework for penetration testing.

- ### **Software Assurance Maturity Model** 
- Analyzes and improves software security throughout the [software development lifecycle](https://www.techtarget.com/searchsoftwarequality/definition/software-development-life-cycle-SDLC).

- ### **Security Knowledge Framework** 
- A web application that explains how to use secure coding principles in different programming languages.

- ### **Security Shepherd** 
- A security training platform for web and mobile applications.

- ### **Web Security Testing Guide** 
- A comprehensive guide to security testing for web applications and web services.

- ### **Zed Attack Proxy** 
- A web app scanner used for penetration testing, as well as for training. It is released under the Apache open source license.
