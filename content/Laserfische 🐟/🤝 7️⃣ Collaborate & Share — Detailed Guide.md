### ➡️ **Why Collaborate in Laserfiche?**

Laserfiche makes teamwork easy — you can **share files**, get **feedback**, and keep everyone working from the same version. No more endless email chains! 📧❌

---

### 📤 **A) Share Documents Internally**

1️⃣ Right-click the file or folder you want to share.  
2️⃣ Click **Send Link** or **Email Entry**.  
3️⃣ Choose **who** to send it to (individuals or groups).  
4️⃣ ✅ The recipient must have permission to open it — adjust permissions if needed.  
5️⃣ The link opens the live file in Laserfiche — no downloading needed.

---

### 🏷️ **B) Add Comments or Annotations**

1️⃣ Open the document.  
2️⃣ Use the **Annotations Toolbar**:

- 📝 Highlight text
    
- ✏️ Add sticky notes or comments
    
- ✅ Strike out text (for drafts)  
    3️⃣ Comments are saved with the document — everyone sees the same feedback.
    

---

### 📄 **C) Check In/Check Out**

When you’re editing a file:  
1️⃣ **Check Out** the document (right-click → **Check Out**).

- 🔒 This locks it so only you can edit it.  
    2️⃣ Make your changes.  
    3️⃣ When done, **Check In** the document so others can edit or view the final version.
    

---

### 🔄 **D) Use Version Control**

Laserfiche keeps track of every version automatically!  
1️⃣ Right-click the file → **Properties** → **Versions** tab.  
2️⃣ See who changed what and when.  
3️⃣ 🔙 Restore an older version anytime if needed.

---

### ✉️ **E) Share Externally (If Allowed)**

Need to share outside your organization? 🌍  
1️⃣ Create a **Public Portal Link** (if your admin allows it).  
2️⃣ Or export the file as PDF → send by secure email.  
3️⃣ ✅ Always check your company’s security policy before sharing externally!

---

### 💬 **F) Set Notifications**

1️⃣ Right-click a folder or file → **Subscribe for Notifications**.  
2️⃣ Get an alert if someone:

- Adds a new file
    
- Edits a file
    
- Deletes a file  
    3️⃣ 📬 Stay in the loop without hunting for updates!
    

---

### 💡 **Tips for Good Collaboration**

✅ Use comments instead of long email threads — everyone stays on the same page.  
🔒 Keep permissions clear — only share with people who need it.  
📌 Use check-in/out for files everyone edits — it prevents accidental overwrites.  
🔍 Version control is your backup plan — nothing’s ever truly lost!
