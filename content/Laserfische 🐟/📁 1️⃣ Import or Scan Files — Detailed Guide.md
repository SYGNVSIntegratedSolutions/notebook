### ➡️ **What You’ll Do**

You’ll learn how to:

- 📂 Import an existing file from your computer
    
- 📠 Scan a paper document into Laserfiche
    
- 🏷️ Add basic info to keep things organized
    

---

### ✅ **Before You Start**

✔️ Make sure you’re logged in to **Laserfiche Client** or **Web Access**  
✔️ Find out where you want to store your document (which folder)

---

### 📂 **A) How to Import a File**

1 **Go to the Folder:**

- In the left panel, click the 📁 folder you want to store the file in.
    

2 **Import the File:**

- 📥 Drag & drop the file from your computer **into the folder window**
    
- **OR** click **Import** on the toolbar, then browse for your file and click **Open**
    

3 **Name the File:**

- Laserfiche may use the original file name. Right-click it if you want to **Rename** it to something clearer.
    

4 **Add a Template (Optional but Helpful):**

- Right-click the new file → **Properties** → select a 📑 **Template** (like Invoice, Contract, etc.)
    
- Fill in any fields (e.g., Date, Client Name)
    

5 **Check It’s There:**

- Make sure you see the file in the folder and can open it.
    

6 🎉 Done! Your digital file is now safely stored.

---

### 📠 **B) How to Scan a Paper Document**

1 **Go to the Folder:**

- Click the 📁 folder where you want to scan the document.
    

2 **Click Scan:**

- On the toolbar, click **Scan** (icon looks like a scanner)
    

3 **Set Up the Scanner:**

- If it’s your first time, select your scanner from the list.
    
- Adjust settings if needed (color, DPI, double-sided).
    

4 **Place the Document:**

- Put your paper in the scanner’s tray 📄
    

5 **Click Start Scanning:**

- Laserfiche will pull in the pages. Watch the preview window to see the scanned pages.
    

6 **Clean Up if Needed:**

- Use the tools to rotate 🌀, reorder ↕️, or delete 🗑️ pages.
    

7 **Name & Save:**

- Enter a clear name for the new file.
    
- Apply a 📑 Template if needed and fill out the fields.
    
- Click **Finish Scanning** — your paper is now digital!
    

---

### 💡 **Extra Tips**

🔍 Scan multiple pages into one file — just keep adding pages before clicking **Finish**.  
🗂️ Use clear names so everyone knows what the file is.  
🔒 Don’t forget permissions — store files in the right folder so the right people can access them.

---

**✅ That’s it!** You now know how to **import or scan files into Laserfiche** — no more lost paperwork! 🎉✨
