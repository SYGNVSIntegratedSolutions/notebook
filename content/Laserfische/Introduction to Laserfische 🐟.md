**Laserfiche** is an enterprise content management (ECM) and business process automation platform used for:

- **Document management** (storing, organizing, and securing digital documents)
    
- **Workflow automation** (routing forms, approvals, and tasks)
    
- **Records management** (retention schedules, compliance)
    
- **Electronic forms** (Laserfiche Forms)
    
- **Searching and retrieving documents quickly**
    

**Basic things you might do in Laserfiche:**  
✅ Scan or import files into a repository  
✅ Organize files in folders with metadata and tags  
✅ Use templates to capture structured data  
✅ Search for documents with keywords, fields, or full-text search  
✅ Automate tasks with workflows (e.g., approvals, notifications)  
✅ Use Laserfiche Forms to collect information from users  
✅ Set permissions to control access

## 📁 **1️⃣ Import or Scan Files**

1️⃣ Open Laserfiche Client or Web Access.  
2️⃣ 📂 Navigate to the folder where you want to add the document.  
3️⃣ ➕ To **import**: Drag & drop the file into the folder or use **Import** from the toolbar.  
4️⃣ 📠 To **scan**: Click **Scan** and follow the prompts to use your scanner.  
5️⃣ 📝 Add metadata (template, fields) if needed.  
6️⃣ ✅ Click **OK** or **Finish** — your document is stored!

---

## 🗂️ **2️⃣ Organize Files**

1️⃣ 📁 Create folders for departments, projects, or document types.  
2️⃣ ✏️ Rename files for clarity (right-click → Rename).  
3️⃣ 🏷️ Add **tags** or **fields** for extra info (right-click → Tags/Properties).  
4️⃣ 📌 Apply **templates** to capture structured data (like invoice #, client name).  
5️⃣ 🔐 Set folder permissions (right-click → Access Rights).

---

## 🔎 **3️⃣ Search for Documents**

1️⃣ Click **Search**.  
2️⃣ 🗝️ Use **Quick Search** for keywords in the file name or content.  
3️⃣ 📑 Use **Field Search** to filter by metadata (e.g., Invoice Number).  
4️⃣ 🗂️ Use **Folder Search** to limit where you look.  
5️⃣ ✅ Click **Run Search** — results will appear. Double-click to open.

---

## 🔁 **4️⃣ Automate Tasks (Workflows)**

1️⃣ Open **Laserfiche Workflow Designer**.  
2️⃣ ➕ Click **New Workflow**.  
3️⃣ 🔗 Drag & drop activities (e.g., Route, Email, Approve).  
4️⃣ ⚙️ Configure each activity’s properties (conditions, users, notifications).  
5️⃣ 🧩 Connect activities in order.  
6️⃣ 💾 Save and **Publish** the workflow.  
7️⃣ ✅ Test it with a sample document.

---

## 📝 **5️⃣ Build Electronic Forms**

1️⃣ Open **Laserfiche Forms**.  
2️⃣ ➕ Click **Create Process** → **New Form**.  
3️⃣ 🖊️ Drag & drop fields (Name, Email, Checkbox, etc.).  
4️⃣ ⚙️ Set field rules (required, show/hide).  
5️⃣ 🔁 Add steps for approvals or routing.  
6️⃣ ✅ Publish the form — share the link or embed it on your site.

---

## 🗄️ **6️⃣ Records Management**

1️⃣ 📑 Apply retention schedules to folders or documents.  
2️⃣ 📅 Set cutoff and retention rules (how long to keep, when to archive).  
3️⃣ 🔒 Mark records as final when ready (prevents edits).  
4️⃣ ✅ Use **Records Manager** to review and destroy expired records.

---

## 🔐 **7️⃣ Manage Permissions**

1️⃣ Right-click a folder or document.  
2️⃣ 👥 Select **Access Rights**.  
3️⃣ ➕ Add users or groups.  
4️⃣ ✅ Assign permissions: Read, Write, Delete, etc.  
5️⃣ 🔒 Save — only authorized users can access.

---

**✨ Tip:** Laserfiche looks different for each organization (custom workflows, forms, security) — so your version may vary slightly!
